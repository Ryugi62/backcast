# Backcast

Plan backward from your deadline. Enter a deadline and the ordered steps (minutes each, mark optional ones). Backcast computes the latest start time for every step, shows your slack, and — if you are already late — which optional steps to cut so you still make it.

- Live demo: https://ryugi62.github.io/backcast/
- Core logic: `backcast.js` (pure function, no DOM). Tests: `node test.js`.
- Built during LovHack Season 3 (Oct 4, 2026 EDT) with AI-assisted development (Claude). No pre-existing code.
